# Security

Please don't report security problems in public issues. Email the ImmPort team through the
contact form at https://www.immport.org with "Security" in the subject, and include the
version and steps to reproduce.

Keep your ImmPort API key private: don't commit it, paste it in issues, or share configuration
files that contain it. If a key is exposed, delete it at https://www.immport.org/auth/api/keys
and create a new one.
