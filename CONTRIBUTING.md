# Contributing

This repository is a published copy of the ImmPort MCP server. Development happens in ImmPort's
internal repository, and each release is exported here with its version tag, so pull requests
can't be merged directly.

Issues are welcome: bug reports, questions and feature requests. When reporting a problem, include:

- the `immport-mcp` version (`pip show immport-mcp`) and your MCP client (Claude Desktop, Claude Code, …)
- what you asked or which tool was called, and the error message
- never your API key

If you'd like to propose a code change, describe it in an issue. The ImmPort team will bring it
into the internal repository and credit you in the release notes.
